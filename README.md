# Predictive Input Buffer v2.1.0 (Android build)

Build from a phone: create a GitHub repo, upload these files (keep folder structure),
go to Actions > "Build Geode Mod" > Run workflow, download "Build Output" -> .geode file.
Install by putting the .geode in the Geode mods folder on your device.

On-screen practice buttons (left side): Buf (toggle buffer), || (freeze), >| (step), CP (checkpoint).
Pause menu "Buffer" button: save/clear a per-level tick profile.
